# Immersive-Me 🈯

بديل **مجاني ومملوك لك** لـ Immersive Translate. متصفح أندرويد بترجمة ثنائية اللغة،
يعمل بمفاتيح الذكاء الاصطناعي **التي تفعّلها أنت** — أو بمحرّك Google المجاني بلا أي مفتاح.

لا اشتراك. لا حساب. لا تتبّع. كل شيء يجري على جهازك.

---

## كيف تحصل على APK

هذا المستودع يبني نفسه تلقائياً على GitHub Actions:

1. كل `push` إلى `main` (أو تشغيل يدوي من تبويب **Actions**) يبني التطبيق
2. بعد ~5 دقائق يظهر ملف APK في:
   - **Releases** ← أحدث إصدار ← `ImmersiveMe-release.apk` (تحميل مباشر، الأسهل)
   - **Actions** ← آخر تشغيل ← Artifacts ← `ImmersiveMe-APK`

3. نزّل الـ APK على التلفون → اضغطه → اسمح بـ "تثبيت من مصادر غير معروفة"

### البناء يدوياً (اختياري)

```bash
git clone https://github.com/<your-user>/<your-repo>.git
cd <your-repo>
gradle assembleRelease      # يحتاج JDK 17
```

## الإعداد (دقيقة واحدة)

افتح ⚙ في التطبيق:

### الخيار ١ — مجاناً تماماً، بلا مفتاح
`المزوّد الفعّال = Google (مجاني)` — جاهز فوراً، بلا تسجيل.

### الخيار ٢ — بمفتاحك الخاص (جودة أعلى، سياق أفضل)
1. اضغط **+ مزوّد جديد**
2. اختر نموذجاً جاهزاً من القائمة (OpenAI، OpenRouter، Groq، DeepSeek، Mistral، Together…)
3. الصق **API Key** الخاص بك، وعدّل الـ MODEL إن أردت
4. اضغط **اختبار** — لازم تشوف "نجح ✓"
5. ارجع للمتصفح → اضغط **译**

> أي واجهة متوافقة مع OpenAI تعمل. كذلك السيرفرات المحلية: llama.cpp على
> `http://127.0.0.1:8080/v1` أو Ollama على `http://127.0.0.1:11434/v1`.

**المفاتيح تُخزَّن محلياً في تخزين التطبيق الخاص على جهازك — لا تُرسل لأي طرف ثالث غير المزوّد نفسه.**

## المزايا

| | |
|---|---|
| **ترجمة ثنائية** | الأصل + الترجمة تحته |
| **وضع ضبابي** | الترجمة مضبّبة وتظهر عند التمرير عليها (مثل Immersive تماماً) |
| **وضع استبدال** | الترجمة بدل الأصل |
| **دفعات ذكية** | حتى 8 فقرات في نداء واحد → استهلاك أقل بكثير من المفاتيح |
| **كاش دائم** | ما يُترجم نفس النص مرتين أبداً، بين الجلسات أيضاً |
| **محتوى ديناميكي** | يترجم المحتوى الجديد (تويتر، إنفينيت سكرول، تطبيقات الويب) |
| **تخطي ذكي** | لا يترجم الكود، الحقول، `translate="no"` |
| **وضع سطح المكتب** | User-Agent لسطح المكتب بضغطة |
| **محرّكات متعددة** | أضف مفاتيح بعدد غير محدود، وبدّل بينها |

## بنية المشروع

```
app/src/main/java/com/minis/imt/
├── MainActivity.kt      ← المتصفح + الجسر بين JS وKotlin
├── TranslateEngine.kt   ← محرّك الترجمة (Google + أي مزوّد متوافق OpenAI)
├── Prefs.kt             ← المزوّدون، المفاتيح، الكاش
└── SettingsActivity.kt  ← شاشة الإعدادات
app/src/main/assets/translate.js   ← محرّك الترجمة المحقون في الصفحة
.github/workflows/build.yml        ← البناء التلقائي
```

**صفر اعتماديات خارجية** — لا أندرويد-إكس ولا OkHttp. كل شيء على واجهات أندرويد
الأصلية. البناء سريع وموثوق ولا ينكسر عند تحديث المكتبات.

## ملاحظة أمنية

التطبيق يحقن جسراً (`ImtNative`) في صفحات الويب ليطلب الترجمة. الجسر لا يمنح
أي وصول للملفات أو الجهاز — وظيفته الوحيدة إرسال نصوص للترجمة. نظرياً يمكن
لصفحة خبيثة أن تطلب ترجمات بلا داعٍ وتستهلك رصيد مفتاحك. إن قلقت من هذا،
استخدم مفاتيح بحدّ إنفاق منخفض، أو محرّك Google المجاني.
